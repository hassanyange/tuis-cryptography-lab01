## Шифр Цезаря

### Принцип работы
- Каждая буква сдвигается на фиксированное число позиций
- Ключ — величина сдвига (k)
- Пример: k=3, А→Г, Б→Д, ..., Я→В

### Математическая модель
\[ T_k(a) = (a + k) \mod 32 \]

---

## Реализация Цезаря

```python
def caesar_encrypt(text, shift):
    result = ""
    for char in text:
        if 'а' <= char <= 'я' or 'А' <= char <= 'Я':
            if char.isupper():
                base = ord('А')
                alphabet_size = 32
            shifted = (ord(char) - base + shift) % alphabet_size
            result += chr(shifted + base)
        else:
            result += char
    return result

def atbash_encrypt(text):
    result = ""
    for char in text:
        if 'а' <= char <= 'я':
            result += chr(ord('я') - (ord(char) - ord('а')))
        elif 'А' <= char <= 'Я':
            result += chr(ord('Я') - (ord(char) - ord('А')))
        else:
            result += char
    return result
